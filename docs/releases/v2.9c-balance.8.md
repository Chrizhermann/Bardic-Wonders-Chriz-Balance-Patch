# v2.9c-balance.8 — Priest-spell copies, kit spell names and Symphony's ending

Released October 14, 2026, on top of balance.7. Six existing components
change; there are no new components. The standalone Abettor tail becomes
**1.2.0**.

- **Priest-spell copies (Darkbloom 1006, Troubadour 1008, Deathsinger 1009,
  New Bard Spells 2008):** each copy comes from the spell that its
  `SPELL.IDS` symbol names instead of a fixed `SPPRxxx` file, so Spell
  Revisions, IWDification and IWD:EE layouts no longer give the kits
  unrelated spells. Copies refresh and block themselves like their sources,
  so a recast no longer stacks with the earlier cast. A symbol without a
  usable spell stops the component with a message. Only Darkbloom has
  bundled fallbacks; it now installs them under its own `C0BDD*` names, so
  no installed file is replaced. Its Mold Touch finds its spreading
  sub-spell again, and the bundled Mold Touch no longer stays a priest spell.
- **Kit descriptions (1006, 1008, 1009):** the Troubadour, Darkbloom and
  Deathsinger descriptions list each granted spell by its installed name, so
  they follow Spell Revisions' names and the game's language.
- **Gallant (1012) and New Bard Spells (2008):** the Gallant receives the new
  bard spells whichever of the two components is installed second.
- **Symphony of the Dark Children (Bard Song Mechanics Tweak 2004, with
  Abettor 1004):** every activation ends with its own round of party
  Invisibility once its song runs out, also while a newer Symphony plays. The
  old ending fired every round while the singer was disabled and never when
  the song ended.

## Install

For a fresh installation, extract the archive into the game folder and run
`Setup-BardicWonders.exe`. The archive contains the full mod and keeps every
other released component unchanged.

An existing installation needs a normal WeiDU reinstall of the changed
components; copying the files alone does not update installed resources.
Symphony still requires 1004 and 2004.

`Abettor-HLA-Rebalance-v1.2.0.zip` is the standalone Abettor tail for an
existing playthrough that should not reinstall component 2004. Install it as
the last component; a playthrough with tail 1.1.0 can reinstall it as 1.2.0.
It still refuses playthroughs whose component 2004 added the Symphony hooks
itself (balance.5 to .7).

## Checks and remaining limits

Release validation passes all **169** resource and installer tests and **50**
WeiDU 249 syntax/version checks, including every shipped installer library.
The tests run the production WeiDU code on synthetic games with vanilla,
Spell Revisions-like, IWD-like and mixed spell layouts, translated and
missing spell names, both Gallant install orders, and the real
component-2004 producer plus altered song controllers, with reinstall,
byte-exact uninstall and rollback of malformed inputs. The kit descriptions
and spell copies also ran on files copied from two EET test installations,
with and without Spell Revisions. No in-game playtest yet.

The Darkbloom Spell Revisions exclusion stays until these copies are checked
in a Spell Revisions game. Symphony's opening and ending have not been
verified in the engine ([issue #5](https://github.com/Chrizhermann/Bardic-Wonders-Chriz-Balance-Patch/issues/5)).
The Troubadour's brief description still repeats the Abettor of Mask text.
Gallant copies still name the bard spells in their identity effects, so a
Gallant's recast can stack, and Inspirations (2002) and High Level Abilities
(2007) still adjust the Gallant only when the kit is installed first. Heroism
exclusivity is not part of this release (see the
[Heroism integration handoff](../heroism-family-integration.md)).

**Brief player check:** in a Spell Revisions game, confirm that a Troubadour's
description and spellbook show Cure Serious Wounds and Cure Critical Wounds
for its third- and fourth-level copies, and that casting its Aid twice
refreshes instead of stacking. With an Abettor who has Symphony, sing once and
confirm the party turns invisible when the song starts and again when it ends
(67 seconds later at Bard level 20, 74 at level 25).
