# v2.9c-balance.5 — complete Bard balance and Symphony compatibility update

This release contains all previously merged Bard balance changes and the pending
Abettor component-2004 compatibility fix. The user reported successful Bard kit,
shared-ability and Abettor testing and approved release on September 16.

## Included changes

- Jester songs/Heckle/Mad Ramble, Skald Warsong, Dancer defenses, Storm Drummer
  Thunderclap, Strategist Checkmate and Kapellmeister support/refresh rebalances.
- Shared HLA changes to Legionnaire's March, Resonating Weapon, Hymn of Requiem,
  Song of Heroism and Song of Freedom, plus the earlier Greater Heroism adjustment.
- Darkbloom song, poison and acid-damage corrections for supported installations.
- Abettor's reduced Symphony bonuses, now correctly recognized after component
  2004 allocates its controller, projectile and feedback strings.
- Standalone Abettor tail **1.1.0** restores a skipped Symphony HLA, preserves
  current self-refresh and later-mod effects, and uninstalls cleanly.

The installer derives payload names from every controller header and resolves the
registered projectile. It rejects malformed or inconsistent resources and validates
all generated hooks before making the HLA available. No installation-specific
resource names, projectile numbers, string references or hashes are embedded.

## Verification

The repository suite includes the unchanged component-2004 producer running in
isolated fake games with different name/projectile allocations, strict malformed
input tests, and byte-preserving tail install/uninstall. A replay using copied
Combined-install resources also passes; the game itself was not changed or launched.
The final suite passes 136 tests and 45 WeiDU 249 syntax/version checks. HLA table
restoration covers both supported widths and rolls back unsupported or inconsistent
tables. Syntax verification requires WeiDU's success message and rejects error
diagnostics even when the process returns exit code zero.

## Installation and limits

Use the full archive for a fresh installation. Shared HLAs require component 2007;
Symphony requires 1004 and 2004. Install kits before shared HLAs, then song mechanics.
The separately attached Abettor tail updates only Abettor in an existing stack.

Darkbloom remains excluded under Spell Revisions (#2); other priest-spell imports
and New Bard Spells/Gallant ordering remain tracked in #3/#4. The intended ordinary
party invisibility at Symphony's opening and finale still requires separate engine
verification (#5). The user accepted the broader kit changes; that does not prove
those two specific events.
